\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}

\vspace{-0.5cm}

This thesis presents the work carried out during my end-of-studies project at \textbf{NTT DATA Morocco}, in the field of artificial intelligence, as part of the Master’s degree in \textbf{Distributed Systems and Artificial Intelligence} at ENSET Mohammedia. The main objective was to design a comprehensive risk analysis and action recommendation platform, built around a conversational AI agent, exploiting data from \textbf{Jira Data Center} (tickets, comments, histories, project metadata).

The developed system integrates an asynchronous backend (FastAPI), a metric computation engine (WIP ratio, stale ratio, Gini coefficient, velocity), a predictive Monte Carlo simulation (10,000 scenarios, percentiles p50 to p95), and a LangGraph orchestration agent coupled with the Mistral LLM (hosted locally in Tétouan). The user interface (React) provides a real-time dashboard, a Jira explorer, automatic alerts, and a detailed view of individual performance (employee scoreboard). The entire platform is industrialised using Docker, Jenkins, and deployed on NTT DATA’s servers.
